# Pathfolio MVP 정의서

> v0.1 · 팀 합의 전 제안안 · 2026-11-07  
> 기준: 사용자 제공 공모전 주제 및 세션 1~3 계획, 확정된 React/Node.js·계정 기반 저장·하이브리드 추천 방식

## 1. MVP 목표

공모전 시연에서 **계정 로그인 → 학업 데이터 등록 → 맞춤 전공트랙 추천(규칙 기반 + AI 설명) → 학년·학기별 교과/비교과 로드맵 생성·저장·관리 → 트랙 변경 시 이수 요건 비교**까지 **끊기지 않는 사용자 흐름**을 구현한다.

실제 한성대 학사정보 자동 연동은 확인되지 않았으므로 **시연용 가상 학생·교과·비교과·전공트랙 데이터**를 우선 제안한다. 시연 데이터는 공식 학교 정보라고 오인되지 않도록 구분한다.

### 기능 우선순위 및 개발 원칙

- **P0 (필수):** 공모전 핵심 기능으로, 최종 시연 전까지 구현 및 검증을 완료한다.
- **P1 (확장):** 서비스 편의성과 완성도를 높이는 기능으로, P0 기능의 구현·검증이 완료된 후 개발한다.

#### 개발 원칙

1. **핵심 흐름 우선:** 학업 데이터 입력·저장 → 전공트랙 추천 → 로드맵 생성·관리 순으로 구현한다.
2. **추천 결과의 재현성:** 동일한 입력과 기준 데이터에 대해 일관된 추천 결과와 근거를 제공한다.
3. **AI 장애 대응:** AI 서비스 장애 시에도 규칙 기반 추천 결과와 기본 설명을 제공한다.
4. **데이터 신뢰성:** 교과·비교과 및 전공트랙 이수 요건의 출처와 적용 기준을 명시한다.
5. **검증 기반 완료:** 각 기능은 정의된 최소 검증을 통과해야 완료로 인정한다.

> 기능 상세, 예외 처리 및 사용자 시나리오는 [`SPEC.md`](SPEC.md)의 요구사항 ID를 따른다.

## 3. MVP에서 하지 않는 것 (제안)

- 교내 학사시스템 실시간 연동·자동 성적 조회(별도 승인/연동 권한 없을 경우).
- 실제 졸업요건 공식 판정 및 자동 전공 배정, 취업 보장 주장.
- 모든 단과대·모든 학년도·모든 비교과 프로그램 완전 지원(검증한 대표 데이터셋으로 시연).
- 상담 챗봇의 광범위한 자유 대화, 자동 시간표 최적화, 수강신청 자동화.
- 모바일 네이티브 앱, 푸시 알림, 외부 SNS 공유, 교직원용 관리자 대시보드.
- 상용 수준의 운영·대량 트래픽·모든 외부 연동.

> 다만 공모전 공식 안내나 제출 서류에 위 항목이 필수라고 명시됐다면 **공식 요구사항이 우선**하며 이 문서의 범위를 수정한다.

## 4. 구현 정책 및 의존성

1. **규칙 엔진 먼저:** 학사 기준 데이터와 계산 구조, 테스트용 입력·기대 결과를 마련한다.
2. **AI는 선택적 설명 계층:** API 장애·요금 초과·지연 시 규칙 결과와 사전 정의된 설명을 제공한다.
3. **로그인 포함:** 서버에 학생별 데이터 저장·권한 검사. DB 제품·ORM·인증 전략은 팀 결정 전까지 가정하지 않는다.
4. **데이터 근거 우선:** 과목/요건은 기준 학년도·출처를 포함하고, 시험 데이터는 `sample` 표기를 일관되게 사용한다.
5. **범위 통제:** 신규 아이디어는 Issue로 등록하되 P0 시연 흐름을 깨면 다음 단계로 미룬다.

## 6. 권장 개발 순서 및 작업 분배

- 1차: `main` 기반 협업 규칙과 공통 문서, React/Express 스캐폴드, DB 및 인증 PoC.
- 2차: 학업 이력 CRUD + 샘플 트랙 요건 + 순수 함수형 추천 계산/테스트.
- 3차: 추천 API 및 AI 설명 폴백 + 로드맵 생성·편집·저장.
- 4차: 트랙 비교 + 통합 테스트 + 오류 처리 + 시연 안정화.

역할을 고정 배분하지 않은 상태이므로 **Issue 단위로 FE / BE·DB·인증 / 추천·데이터·QA 작업을 나누고 팀원이 협의**한다. 변경이 잦은 공통 파일과 API 계약은 담당자 중복을 최소화한다.

## 7. MVP 성공 조건 / 시연 인수 테스트

1. **AT-01:** 새 계정 가입·로그인·로그아웃, 재로그인 이후 데이터 복원.
2. **AT-02:** 서로 다른 사용자 A/B 계정 간 프로필·학업 이력·로드맵 접근이 격리됨.
3. **AT-03:** 2개 이상 시연 프로필로 전공트랙 후보가 다르게 도출되며, 입력·규칙 근거를 확인 가능.
4. **AT-04:** AI가 정상일 때 이해하기 쉬운 설명을 제공하고, 실패 시 핵심 추천·로드맵 기능은 유지.
5. **AT-05:** 학년·학기별 교과·비교과 항목 생성·수정·완료·저장·재조회 가능.
6. **AT-06:** 다른 트랙으로 비교할 때 공통·추가 필요 요건이 표시되고 기존 로드맵은 보존됨.
7. **AT-07:** 빈 입력, 유효하지 않은 학점, 서버 오류, 데이터 미존재 상태에 친절한 오류 안내가 표시됨.
8. 시연에 쓰이는 전공·과목·학생 정보는 **가상/검증 출처** 및 학사 기준 연도가 명시됨.
9. 최종 배포/로컬 실행 절차가 README에 **실제 명령으로 검증**되어 기록됨.
